📘 ARCHITECTURE & HOSTING GUIDE

How to Upload & Stream Video on Your Cafe Website

Compare the 4 recommended production architectures for uploading, hosting, and streaming video smoothly without lag or high server bills.

RECOMMENDED FOR CAFES
⚡

Option 1: YouTube (Unlisted) or Vimeo Embed

Upload your cafe reels to YouTube as "Unlisted" (only visible on your website) and embed via an optimized iframe.

  • Cost: 100% Free forever (unlimited views & bandwidth).
  • Streaming Engine: Google's global CDN with automatic 360p / 720p / 1080p / 4K adaptive bitrate.
  • How to use: Upload reel on YouTube Studio → Copy link → Paste into TFH Cinema Player!
PRO CINEMATIC CHOICE
🚀

Option 2: Cloudflare Stream or Bunny.net Stream

Dedicated video streaming cloud designed for clean, white-label websites with zero third-party branding.

  • Cost: Bunny.net: ~$0.005 / GB; Cloudflare Stream: ~$5 / month.
  • Streaming Engine: Real HLS (.m3u8) / DASH with instant sub-second start time.
  • How to use: Upload MP4 in Bunny or Cloudflare dashboard → copy HLS stream URL → paste into site.
SELF-HOSTED STORAGE
☁️

Option 3: AWS S3 + CloudFront / Supabase Storage

Upload optimized MP4/WebM files to cloud object storage behind a CDN edge cache.

  • Cost: Free tier on Supabase (1GB); AWS S3 pennies per gigabyte.
  • Streaming Engine: Native HTML5 Range Requests (HTTP 206 Partial Content).
  • Best practice: Compress video using Handbrake/ffmpeg with H.264 CRF 22 + faststart flag for instant playback.
ZERO BACKEND REQUIRED
🎥

Option 4: In-Browser Client-Side Streaming

Our built-in uploader uses the browser's native File API and URL.createObjectURL().

  • Cost: 100% Free, runs entirely inside the client's browser.
  • Instant preview: You can drop any MP4 right now into the TFH Cinema Studio above and watch it stream!
  • Next step: When ready to make it permanent for all website visitors, choose Option 1 (YouTube) or Option 2 (Bunny/Cloudflare).

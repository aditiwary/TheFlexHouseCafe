## 🍽️ About the Project

Official responsive website for **The Flex House Cafe**, featuring:
- **Interactive Digital Menu & Filtering:** Pizzas, Burgers, Pastas, Kurkure Momos, Indo-Chinese Wok, Shakes, and Combos.
- **Table Reservation & Party Booking System:** Instant booking request flow with date & time selection.
- **Customer Reviews & Testimonials:** Highlighted customer ratings and feedback.
- **Location & Contact Integration:** Google Maps directions, WhatsApp ordering, and direct calling.
- **Modern Responsive Design:** Designed for mobile, tablet, and desktop with smooth UI animations and dark-mode aesthetics.

---

## 🚀 Getting Started

### Local Development

You can serve this website using any static HTTP server:

```bash
# Using Python
python3 -m http.server 3000

# Or using Node.js / npx
npx serve .
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
